# Changelog

## 1.0.0

First public release.

- Pomodoro cycle with short / long breaks, pause, skip, reset and ±1 minute
- Big fixed-width ASCII clock, progress bar, cycle dots
- Ripening tomato during focus, steaming coffee cup during breaks, confetti on completion
- Interactive startup questions with remembered settings
- Daily stats, streak and 7-day sparkline (`--stats`)
- 5 colour themes (switch live with `t`)
- Native notifications and sounds on Linux, macOS and Windows
- English and Ukrainian UI, Ukrainian keyboard layout hotkeys
- Remaining time in the terminal / taskbar title
