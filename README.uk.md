## ✨ Можливості

- **Великий годинник без «стрибків»**: цифри фіксованої ширини, прогрес-бар і крапки циклу (`● ● ○ ○`).
- **Класичний цикл Pomodoro**: фокус → коротка перерва → … → довга перерва після N помідорів.
- **Питає на старті**: скільки фокусу, скільки перерви й над чим працюєш. Наступного разу пам'ятає відповіді.
- **Нативні сповіщення й звуки** на кожній ОС (деталі нижче) і **конфеті** після завершеного помідора 🎉
- **Статистика, що зберігається**: помідори за сьогодні, **серія** днів поспіль і спарклайн за 7 днів (`▄·▅█▆▃▅`), усе локально.
- **5 колірних тем**, які перемикаються наживо: `classic`, `ocean`, `matrix`, `sunset`, `mono`.
- **Керування наживо**: `+` / `-` змінюють поточну фазу на хвилину, пауза, скидання чи пропуск у будь-який момент.
- Залишок часу в **заголовку терміналу чи вікна**, тож його видно з іншого вікна.
- **Інтерфейс українською й англійською** (визначається автоматично), а гарячі клавіші працюють і з українською розкладкою.
- Підлаштовується під маленькі термінали: якщо місця мало, прибирає малюнок.
- Один файл і **жодних залежностей**: лише стандартна бібліотека Python.

## 📦 Встановлення

**Просто запустити** (нічого встановлювати не треба):

```bash
curl -O https://raw.githubusercontent.com/YOUR_USERNAME/pomodoro-cli/main/pomodoro.py
python pomodoro.py
```

**Або встановити команду `pomodoro`:**

```bash
pipx install git+https://github.com/YOUR_USERNAME/pomodoro-cli
# або: pip install git+https://github.com/YOUR_USERNAME/pomodoro-cli
pomodoro
```

Потрібен Python 3.10+. На Windows використовуй Windows Terminal або будь-який термінал з підтримкою ANSI (Windows 10+).

## 🚀 Використання

```bash
pomodoro                         # інтерактивно: спитає фокус / перерву / задачу
pomodoro --yes                   # взяти останні налаштування без питань
pomodoro --work 50 --short 10    # свої тривалості (хвилини)
pomodoro --task "Курсова"        # показати, над чим працюєш
pomodoro --manual                # чекати на [пробіл] перед кожною фазою
pomodoro --theme ocean           # обрати тему
pomodoro --stats                 # статистика за 7 днів
```

### ⌨️ Клавіші

| Клавіша | Дія |
| --- | --- |
| `пробіл` | пауза / продовжити |
| `s` (`і`) | перейти до наступної фази (незавершений помідор **не** зараховується) |
| `r` (`к`) | почати поточну фазу спочатку |
| `+` / `-` | додати / прибрати хвилину |
| `t` (`е`) | змінити тему |
| `m` (`ь`) | вимкнути / увімкнути звук |
| `q` (`й`) | вийти (`Ctrl+C` теж працює) |

### 🔧 Параметри

| Параметр | Опис |
| --- | --- |
| `--work N` | тривалість фокусу в хвилинах (за замовчуванням `25`) |
| `--short N` | коротка перерва (за замовчуванням `5`) |
| `--long N` | довга перерва (за замовчуванням 3× коротка) |
| `--cycles N` | помідорів до довгої перерви (за замовчуванням `4`) |
| `--task ТЕКСТ` | над чим працюєш |
| `--theme НАЗВА` | `classic` · `ocean` · `matrix` · `sunset` · `mono` |
| `--lang en\|uk` | мова інтерфейсу (за замовчуванням визначається автоматично, потім запам'ятовується) |
| `--yes` | не питати, взяти останні налаштування |
| `--manual` | чекати на `пробіл` перед початком кожної фази |
| `--no-sound` | без звуку |
| `--stats` | показати статистику за 7 днів і вийти |
| `--version` | показати версію |

## 🖥️ Як підлаштовується під ОС

| | Linux | macOS | Windows |
| --- | --- | --- | --- |
| Введення з клавіатури | `termios` | `termios` | `msvcrt` |
| Сповіщення | `notify-send` | `osascript` | PowerShell toast |
| Звук | `paplay` / `pw-play` / `canberra` | `afplay` | `winsound` |
| Папка з даними | `~/.local/share/pomodoro-cli` | `~/Library/Application Support/pomodoro-cli` | `%APPDATA%\pomodoro-cli` |

Якщо сповіщення чи програвача звуку немає, застосунок тихо переходить на дзвоник терміналу.
Налаштування й статистика лежать у невеликому `stats.json` у папці з даними. Видали його, щоб усе скинути.

> **Про тестування:** розроблено й перевірено на Linux. Для macOS і Windows CI перевіряє синтаксис і запуск, а от сповіщення на цих системах тестувалися менше. Issues і PR дуже вітаються!

## ❓ FAQ

**Цифри виглядають зламаними чи зсунутими.**
Використовуй шрифт терміналу з блоковими символами (майже кожен моноширинний шрифт підійде).

**На Linux не приходить сповіщення.**
Встанови `libnotify` (`notify-send`) і переконайся, що запущений демон сповіщень.

**Чи можна змінити кольори?**
Натисни `t` під час роботи або запусти з `--theme`. Теми це прості словники на початку `pomodoro.py`.
